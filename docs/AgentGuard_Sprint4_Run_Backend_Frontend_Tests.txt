AgentGuard Sprint 4 v1.0.0 - Backend, Frontend, Database and Test Commands
=============================================================================

This guide runs the final AgentGuard Sprint 4 codebase locally without Docker.

Primary architecture:

    React + TypeScript + Vite
              |
              v
           FastAPI
              |
              v
      SQLModel / SQLAlchemy
              |
              v
           Alembic
              |
              v
        PostgreSQL 16

Local URLs:

    Frontend: http://localhost:5173
    API:      http://localhost:8000
    Swagger:  http://localhost:8000/docs
    Health:   http://localhost:8000/health

1. Start PostgreSQL
===================

    brew services start postgresql@16
    pg_isready

If PostgreSQL 16 is not installed:

    brew install postgresql@16
    export PATH="$(brew --prefix postgresql@16)/bin:$PATH"

2. Create local databases once
==============================

    psql postgres

Inside psql:

    CREATE ROLE agentguard
    WITH LOGIN PASSWORD 'agentguard_dev_password';

    CREATE DATABASE agentguard
    OWNER agentguard;

    CREATE DATABASE agentguard_test
    OWNER agentguard;

    \q

If these already exist, skip this step.

3. Backend setup
================

From the repository root:

    cd apps/api
    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt

For later sessions:

    cd apps/api
    source .venv/bin/activate

4. Run development migrations
=============================

    export DATABASE_URL="postgresql+psycopg://agentguard:agentguard_dev_password@localhost:5432/agentguard"
    export ENVIRONMENT=development
    export SEED_DEMO_DATA=true
    export DEMO_MODE=true
    export MCP_MOCK_MODE=true
    export AI_PROVIDER=mock

    alembic upgrade head
    alembic current
    alembic history

Expected final version:

    AgentGuard API v1.0.0

Expected Alembic head:

    20260808_0002

5. Run the backend
==================

Terminal 1:

    cd apps/api
    source .venv/bin/activate

    export DATABASE_URL="postgresql+psycopg://agentguard:agentguard_dev_password@localhost:5432/agentguard"
    export ENVIRONMENT=development
    export SEED_DEMO_DATA=true
    export DEMO_MODE=true
    export MCP_MOCK_MODE=true
    export AI_PROVIDER=mock

    alembic upgrade head
    uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Verify:

    curl http://localhost:8000/health
    open http://localhost:8000/docs

Useful final release endpoints:

    http://localhost:8000/api/v1/release/readiness
    http://localhost:8000/api/v1/release/demo-flow
    http://localhost:8000/api/v1/release/submission-checklist

6. Run the frontend
===================

Terminal 2:

    cd apps/web

    corepack prepare yarn@1.22.22 --activate

8. Backend tests against PostgreSQL
===================================

Use the test database, not the development database:

    cd apps/api
    source .venv/bin/activate

    export DATABASE_URL="postgresql+psycopg://agentguard:agentguard_dev_password@localhost:5432/agentguard_test"
    export ENVIRONMENT=test
    export SEED_DEMO_DATA=false
    export MCP_MOCK_MODE=true
    export AI_PROVIDER=mock

    alembic upgrade head
    pytest -q

11. Inspect PostgreSQL
======================

    psql -h localhost -U agentguard -d agentguard

Inside psql:

    \dt
    SELECT * FROM alembic_version;
    SELECT id, name, effect, priority, active, version FROM policy ORDER BY priority DESC;
    SELECT correlation_id, agent_name, action, resource_name, decision FROM actionrequest ORDER BY created_at DESC;
    SELECT event_type, result, actor_email, created_at FROM auditevent ORDER BY created_at DESC;
    SELECT * FROM toolexecution ORDER BY created_at DESC;
    \q

12. Optional Docker Compose
===========================

    cp .env.example .env
    docker compose up --build

Open:

    http://localhost:5173
    http://localhost:8000
    http://localhost:8000/docs

Stop:

    docker compose down

Reset Docker database volume:

    docker compose down -v

13. Final demo checklist
========================

- Open final UI at http://localhost:5173.
- Show readiness score and final release version.
- Run ALLOW scenario.
- Run REQUIRE_APPROVAL scenario.
- Run DENY scenario.
- Run governed agent prompt.
- Approve/reject a pending approval.
- Show tool execution state.
- Show AI decision explanation.
- Filter and export audit events.
- Show final readiness and demo-flow tab.
- Show GitHub CI checks and Jira board.
